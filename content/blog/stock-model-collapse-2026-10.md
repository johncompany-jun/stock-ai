半年近くかけて 4モデルのアンサンブル予測を組んできましたが、本番 D1 に蓄積された 1万件以上の実データで集計し直したところ、**4モデル全部が勝率 50% 前後** という結果に。アンサンブル重みを計算したら、実質 1モデル依存の状態でした。

build in public の記録として、何が起きたか、どう診断したか、どう方向転換したかをまとめます。

## 4モデル体制の意図

もともとの狙いはシンプルで、「単体では弱いモデルでも、多角的に組み合わせれば勝率が上がる」というプロの定石をなぞることでした。

| モデル | 役割 |
|---|---|
| LSTM | 過去のパターンから翌5日のリターン予測 |
| SMA cross | 短期/長期移動平均のクロスでトレンド捕捉 |
| RSI reversal | 売られすぎ/買われすぎからの逆張り |
| Volume breakout | 出来高急増を順張り |

これを「予測方向が一致したら信頼度 up」で合成していく設計でした。

## 本番データで集計し直した結果

集計日: 2026-10-08、対象: 本番 D1 の `predictions` テーブル、5日先リターン方向の的中率 (hit rate)。

| モデル | n | 勝率 (hit) | アンサンブル重み |
|---|---|---|---|
| lstm_v1 | 11,595 | **49.94%** | **0** |
| sma_cross_v1 | 13,024 | **47.83%** | **0** |
| volume_breakout_v1 | 3,160 | **43.70%** | **0** |
| rsi_reversal_v1 | 2,831 | **50.87%** | **0.87** |

全モデル 50% 前後。コイン投げと差がありません。
しかもアンサンブル重みは `max(0, hit% - 50)` で計算しているので、RSI だけが辛うじて 50 超え → **MIX は実質 RSI 単体** になっていました。

## さらに悪いことに — RSI の 71% は「予測フラット」

集計を進めると、RSI reversal_v1 の予測の 約71% が `predicted_close ≒ last_close` の状態、つまり「予測変化ゼロ」でした。
期待値計算に乗らない予測ばかりで、UI 上は「+0.00%」が並ぶ状態です。

結果として、サイト上の daily_picks tier A (高信頼度) は 1ヶ月で **累計 +2% 程度** のリターンにとどまり、「見る価値のある数字がない」というのが正直な評価でした。

## 一方で、過去の限定サンプルでは良い数字だった

実は 2026-08-04 時点の「予測フラットを除いた h=20 サンプル」では、こんな数字が出ていました。

| モデル | 勝率 (h=20) |
|---|---|
| LSTM | 52.1% |
| SMA | 44.5% |
| RSI | 53.0% |

さらに **LSTM と SMA が同じ方向を向いたとき** のバックテストでは、5日先の的中率が 57.2% まで上がる (+9pt 向上) ことも観測されていました。

ここでミスリードされました。「サンプル増やせばこの数字は維持される」と思い込んでいたら、本番で全部 50% 前後に収束した、という流れです。

## 診断: 短期と長期で向いているモデルが違う

振り返りで一つ分かったことがあります。
ホライズン別に集計すると:

| ホライズン | 強いモデル |
|---|---|
| 5-10日 | SMA cross > LSTM |
| 20-40日 | LSTM > SMA cross |

短期は「トレンドフォロー」のほうが素直に効き、
長期は「過去類似パターンからの予測」が意味を持ち始める、ということのようです。

ところが現状のサイト UI は 5日先予測だけを前面に出していました。
長期で効くはずの LSTM を 5日ホライズンで評価していたので、強みが出なかったのです。

## 「見る価値のある数字」を取り戻すためのピボット

ここから戦略を切り替えます。

### 1. 「予測」から「検索+統計」へ

5日後の値動きを数字で予測するのは、個人データ量と単系列モデルでは原理的に無理筋と判断。
代わりに「**過去のこのチャート形状の後、N回中M回が上がった**」というパターンマッチ + 過去勝率表示に軸を移します。

未来を当てに行くのではなく、過去の類似ケースを提示して、「これを根拠に判断してください」というスタンスです。

### 2. RSI モデルは消さず、アンサンブル多様性担当として残す

単体性能ではなく、「順張り (SMA) ばかりだと逆張りの転換点を取れない」という理由で、
RSI reversal_v1 はアンサンブル多様性のために残します。
ただしサイト UI 上の 1モデルとしての前面露出は停止。

### 3. FX モデルで試している MLP + kNN の手法を株にも移植

実は FX サイドでは、同時期に 5-seed MLP アンサンブル + kNN (過去類似日検索) で、OOS 261日の勝率 54.8% を出しています。
こちらの手法を株にも持ってくる予定です。

## 何よりの教訓

**本番データで集計し直すまで、気付けませんでした。**

バックテストの限定サンプルで良い数字が出ると、「これは行ける」と思い込みがちです。
本番運用で 1万件以上の実データが溜まるまで待って集計し直すと、全く違う現実が見えました。

同じことで悩んでいる個人開発者の方、本番 D1 (または相当のストレージ) に数千件以上溜まるまで、
過度な期待で UI を飾らないことをおすすめします。

build in public として、負けの記録も残しておきます。
