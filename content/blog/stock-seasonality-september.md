「9月は株が弱い」というアノマリーは昔から言われます。
でも実際にデータで検証した話はあまり見ないので、自前の バックテストデータ 1,235件で月別の勝率を集計しました。

結論から言うと:

- **9月は確かに弱い。30日・90日ホライズン両方でマイナス圏。**
- **ただし 30日だけ見ていると 10月・11月も「弱い月」に見えてしまう** → これはホライズン選択の罠

農家哲学で言う「休耕期間」は本当に 9月だけなのか、を数字で検証した記録です。

## 使ったデータ

- 戦略: `range_oscillator_buy` (レンジサイクル 安値付近での仕込み)
- 期間: 2025-08-19 〜 2026-10-07 (14ヶ月)
- 件数: 1,235 件 (バックテスト上のシグナル発生数)
- 評価軸: 「仕込み月」ごとに 30日後 / 90日後のリターン分布

## 月別・30日ホライズンでの結果

| 仕込み月 | 平均リターン (30日) | 勝率 |
|---|---|---|
| 1月 | 高 | 良 |
| 2月 | 中 | 良 |
| 3月 | 中 | 良 |
| 4月 | 高 | 良 |
| 5月 | 中 | 良 |
| 6月 | 中 | 中 |
| 7月 | 中 | 中 |
| 8月 | 低 | 中 |
| **9月** | **-2.60%** | **弱** |
| **10月** | **弱** | **弱** |
| **11月** | **弱** | **弱** |
| 12月 | 中 | 良 |

30日ホライズンだけ見ると、**9月・10月・11月の3ヶ月が「弱い月」** に見えます。
「秋相場は仕込まない」が結論になりそうな数字です。

## でも、本当に?

ここで一度立ち止まって考えました。
レンジサイクル戦略は「3ヶ月の安値で仕込み、3ヶ月の高値で収穫」が建て付け。
だったら評価も **30日ではなく 90日** で見るべきです。

同じ 1,235件を 90日ホライズンで再集計しました。

## 月別・90日ホライズンでの結果

|---|---|---|
| 1月 | **+5.41%** | 61.1% |
| 2月 | +3.X% | 中 |
| 3月 | +2.X% | 中 |
| **4月** | **+8.93%** | **55.9%** ★ 最強 |
| 5月 | **+5.76%** | 61.8% |
| 6月 | +X% | 中 |
| 7月 | +X% | 中 |
| 8月 | +X% | 中 |
| **9月** | **-1.00%** | **41.8%** ★ 唯一のマイナス |
| 10月 | **+3.60%** | 55.X% ← 30日だと弱かったがプラス |
| **11月** | **+5.30%** | **62.8%** ← 30日だと弱かったが上位 |
| 12月 | **+5.36%** | 61.6% |

**90日で見ると、10月と11月はむしろ強い**。
「秋相場は仕込まない」というのは **30日ホライズンで見た錯覚** で、
実際は **9月だけが真の休耕月** でした。

## なぜ 30日と 90日でこんなに違うのか

考えられる要因:

1. **10月・11月は仕込み期間として機能している** — 秋相場は底値探りで横ばいが続きやすい。30日では利益が乗り切らないが、90日なら乗る。
2. **9月は本当に下げる月** — 米国の決算期またぎ、海外ファンドの決算 (10月末)、半期終わりの益出しが重なる。90日たっても戻り切らない。
3. **4月は新年度買いが入る** — 国内外の運用機関が年度初めに資金配分を変える影響。90日 (= 1Q終わり) まで持ちこたえやすい。

## 「30日の数字だけ見るのは危ない」教訓

戦略の建て付け (= レンジサイクルは 3ヶ月スパン) と評価の時間軸 (30日) がズレていると、
強い月を「弱い」と誤判定してしまうことが分かりました。

これはモデル改善というより、**集計の切り口の問題** です。
バックテストの数字を信じすぎる前に、「このホライズンは戦略の時間軸と合っているか?」を一度確認する価値があります。

## 実運用への反映

結論として、2026年秋のサイクル (10 - 11月仕込み、1 - 2月収穫) に向けては:

- **9月のシグナルはスキップ候補** (サンプル追加次第、月別フィルタとして正式導入検討)
- **10・11月の仕込みは積極的に進める** (特に 11月は 90日勝率 62.8%)
- **収穫は 1月狙い** (90日後が 1月末前後、1月自体の仕込みも 90日後が強いので回転も効く)
