このサイトでは、日本株と FX の AI 予測を毎日検証して公開しています。
「個人でこんなサイト運営したらいくらかかるの?」とよく聞かれるので、
全部公開します。

**結論: 月 1,000 円いきません。**

## 月額コスト内訳

| 項目 | 料金 | 用途 |
|---|---|---|
| Cloudflare Workers Paid | **$5 / 月** (約 750 円) | サイトを配信するサーバー |
| Cloudflare D1 | 無料枠内 | データベース (株・FX の価格、予測結果) |
| GitHub Actions | 無料枠内 (月 2,000 分まで) | AI の学習と毎日の予測実行 |
| ドメイン (stock-ai.uk) | 年 1,500 円 → **月 125 円** | サイトのアドレス |
| Resend | 無料枠内 (月 3,000 通まで) | 配信希望者へのメール送信 |
| **合計** | **月 875 円** | |

これで、

- 毎日 1 回、日本株の全銘柄をスキャンして AI が予測を出す
- 毎日 1 回、ドル円の寄付方向を AI が予測する
- 全部をデータベースに保存
- サイトに最新情報を SSR で表示

という運用が回っています。

## なぜここまで安く済むか

### 1. Cloudflare のインフラが異常に安い

Cloudflare Workers は「無料枠から始められるサーバー」として有名ですが、
有料化しても **月 $5 で、1,000 万リクエスト / 月まで** 入っています。
個人サイトのアクセスを考えると、ほぼ使い切れません。

Cloudflare D1 (データベース) も、無料枠だけで 500 万行の読み書きが収まります。
個人の投資データなら十分。

### 2. AI 学習は「毎日動かすマシン」ではなく「毎日動く無料枠」で

ディープラーニング系の AI 学習は、本来 GPU サーバーで走らせます。
AWS だと GPU インスタンスで 1 時間数百円。常時稼働させると月数万円。

このサイトでは、GitHub Actions という「毎日自動実行できる無料枠」で学習と推論を回しています。
GitHub Actions は 1 ヶ月 2,000 分 (= 33 時間) まで無料。
AI の学習が週 1 回 10 分、推論が毎日 1 回 1 分 (= 月 30 分) なので、余裕で収まります。

### 3. ドメインは「変わり種を安く」

ドメインは `.com` だと年 1,500-3,000 円くらいしますが、
`.uk` のような国別ドメインを選ぶと、安い場所で年 1,000-1,500 円で取れます。
Cloudflare Registrar は原価販売なので、ここで取るとさらに安いです。

## もしここに AI 学習を課金で加えたら

もし「もっと巨大なモデル」で学習したい場合、

- OpenAI の学習 API: 1 回数十ドル
- Google Vertex AI: 1 時間数ドル
- Hugging Face Spaces: 月 $9 の有料枠

このあたりが現実的な選択肢。
でも個人レベルで月 1,000 円を超えると「ちょっと躊躇する」ラインなので、
今はシンプルなモデル (5-seed MLP + kNN) で済ませています。

## もしアクセスが 10 倍、100 倍になったら

Cloudflare Workers の月 $5 プランは、1,000 万リクエスト / 月まで。
今のアクセス数の 1,000 倍くらいまでは、追加料金ゼロで耐えます。

D1 も、月 500 万行の読み書きまで無料。
その先は 100 万行あたり $0.001 の従量課金で、
10 倍アクセス増でも月数十円の追加。

**要するに、個人サイトレベルでは "値段を気にする必要がほぼない" 構成** です。
これは Cloudflare の価格設定が反則的に安いおかげで、
別の商用クラウドで同じことをやると月数万円になります。

## 結論

- **月額 1,000 円いかない** で、個人の投資 AI サイトは運営できる
- その鍵は Cloudflare (サーバー + DB) + GitHub Actions (学習)
- 「月いくらで動くか」を気にする個人開発者には、この構成はおすすめ

同じことを AWS や GCP でやると月数千円 - 数万円になるので、
「とりあえず始めてみる」ハードルがぐっと下がります。
投資 AI に限らず、個人開発でサーバー費用が気になる方の参考になれば。
